# ─── LIGHTWEIGHT requirements for testing on a laptop ─────────────────────────
# Excludes opencv/ultralytics/torch (theft detection / YOLO) on purpose —
# these are large downloads and not needed to test registration + the
# recommendation engine. cv/theft_detection.py already handles their
# absence gracefully (see the try/except around `from ultralytics import YOLO`
# and `import cv2`), so the rest of the app runs normally without them.
#
# VERSIONING NOTE: the original requirements.txt pins exact old versions
# (e.g. numpy==1.26.4, pydantic==2.7.1). Those versions predate Python 3.14
# and have no prebuilt wheel for it, which makes pip try to compile from
# source and fail with "metadata-generation-failed" on a machine without
# C build tools (Visual Studio Build Tools on Windows). This file uses
# minimum-version constraints (>=) instead of exact pins so pip picks a
# current release with a prebuilt wheel for whatever Python you have.
# If you're on Python 3.11-3.13, the original requirements.txt pins also
# work fine -- this file is specifically for newer Python versions like 3.14.
#
# If you later want the full system including theft detection, use the
# original backend/requirements.txt instead of this file.
